# Exynos 7420 common device tree
Common device tree for Exynos 7420 devices <br>

Based off the Exynos7420 source code found at https://github.com/Exynos7420/android_device_samsung_universal7420-common/tree/lineage-18.1 with various improvements

> **Note (`@eiarf` fork):** The Android 15 / Linux 6.6 bring-up commits on this branch (AIDL V3 V4L2/SoftISP Camera HAL, GNSS/NFC/IR/MAX86900 bring-up, SELinux rules, PowerHAL/task_profiles, and boot stability fixes) were **authored and debugged by an LLM (Large Language Model)**, hardware-verified on `SM-G920F` (`zeroflte`). Companion fixes & flashable release: https://github.com/eiarf/zeroflte-android15-fixes
