## 2. Temuan Diagnostik Baseline (`v0-baseline` pada `06157df6085a9c3c`)
1. **Kamera Delay (~250–450 ms) & ~15 fps (`901/1211 frames dropped` di `exynos7-flite`):**
   - `s5c73c2.c` (`s5k2p2_modes[1]`, `2664x1500`) memakai `vts_def = 1586` -> **60.05 fps**, membatasi eksposur preview ke <=16.5 ms (gelap/noisy).
   - `v4l2_pipeline.cpp` mengalokasikan 4 buffer V4L2 FIFO dan `dequeueFrame()` hanya mengambil buffer **tertua** tanpa membuang frame usang (*stale*).
   - `soft_isp.cpp` melakukan `stageRaw()` single-threaded pada DMA-BUF uncached, 4 worker thread, dan alokasi `std::vector` per baris pada `chromaNrPtrRow()`.
2. **Kualitas Kamera:**
   - `sampleTapCell()` merata-rata kedua green diagonal (`(g0+g1)>>1`), menurunkan resolusi efektif di JPEG penuh; `writeRgba()` & `writeJpeg()` belum punya 4-neighbor DPC & Chroma NR; `V4l2Pipeline::closeNodes()` tidak menonaktifkan media link per-pipeline.
3. **Cepat Panas (`exynos-therm = 59.0°C` saat idle, lebih panas saat NewTube):**
   - `CONFIG_CMDLINE` masih menyalakan **`slub_debug=FZPU,kmalloc-16`** dan **`loglevel=8 ignore_loglevel`**.
   - `cpu_atlas_opp_table` (Cortex-A57) di `exynos7.dtsi` **overvolt +43.75 mV s/d +87.5 mV** di atas tabel resmi Samsung ASV0 v15 (`volt_table_big_asv_v15` di branch `tw70-stock`).
   - `powerhint.json` menyetel `TAUClampBoost DefaultIndex = 2` (`top-app/cpu.uclamp.min = 15%` permanen) & GPU `544 MHz` 5 detik per `LAUNCH`, mendorong decode video software (`c2.android.*` di NewTube) ke core A57.
   - Throttling thermal di `exynos7.dtsi` baru efektif di **80°C** (`map0` 75°C hanya membatasi 1704 MHz sementara `powerhint.json` sudah membatasi 1500 MHz).
   - `CONFIG_LTO_NONE=y` masih aktif.
4. **Glitch Layar Sesekali:**
   - `dmesg` mencatat berulang `panfrost 14ac0000.gpu: Unhandled Page fault` (`JOB_BUS_FAULT` / `DATA_INVALID_FAULT`) tepat setelah `panfrost_gem_shrinker_scan`: `panfrost_gem_purge()` melepas MMU mapping tanpa mengecek `dma_resv_test_signaled(shmem->base.resv, DMA_RESV_USAGE_BOOKKEEP)` maupun `obj->import_attach`.
   - `exynos-decon` mencatat `no TE for 50 ms, frame sent without it` dan `xfer_ms = 0,...,5377` sementara `bus-disp` terkunci di `100 MHz` (`powersave`) padahal `160–266.7 MHz` memakai tegangan `650 mV` yang sama.
5. **Bug ZRAM Boot Log:**
   - `init.samsungexynos7420.rc` memanggil `swapon_all` dua kali (memicu `zram: Cannot change disksize for initialized device` & `mkswap failed`).

   - Chip BCM4358A3 memiliki erratum kehilangan MSI saat menulis `D3_ACK` ke shared TCM (`CSP:999857` di driver resmi `dhd_pcie.c`), ditambah urutan `BRCMF_H2D_HOST_D0_INFORM_IN_USE` di patch `0015` dikirim *sesudah* `D0_INFORM` saat resume (seharusnya dikirim *sebelum* masuk D3 sesudah `D3_ACK` sesuai `dhd_pcie.c:3393`), serta memanggil `brcmf_fw_crashed()` ketika userspace masih frozen mematikan `wlan0` permanen.
   - **Solusi (`0023-brcmfmac-pcie-d3-ack-poll-and-d0-inform-order.patch`):** Poll `brcmf_pcie_handle_mb_data()` tiap `50 ms` selama menunggu `D3_ACK`, kirim `D0_INFORM_IN_USE` + `brcmf_pcie_intr_disable()` sebelum D3, kirim hanya `D0_INFORM` saat resume, dan pulihkan ke D0 (`-EBUSY`) tanpa `brcmf_fw_crashed()` bila timeout terjadi saat link aktif.
5. **GPU Mali-T760 Shader Fault (`INSTR_INVALID_ENC` / `gpu sched timeout` di PPSSPP) & Undervolt Cortex-A53 di Bawah `ASV0` (`0024`):**
   - Patch `0008` menurunkan `gpu_opp_table` `12.5 mV` di bawah batas minimum `volt_table_g3d_asv_v15` `ASV0` dan menurunkan `cpu_apollo_opp_table` (Cortex-A53) hingga **`43.75–93.75 mV` di bawah `volt_table_lit_asv_v15` `ASV0`** (`675 mV` vs `768.75 mV` @ `400 MHz`, `825 mV` vs `875 mV` @ `800 MHz`).
   - **Solusi (`0024-arm64-dts-exynos7420-restore-asv0-safe-gpu-and-a53-voltages.patch`):** Pulihkan seluruh titik tegangan `gpu_opp_table` (`762.5..893.75 mV`) dan `cpu_apollo_opp_table` (`768.75..1162.5 mV`) persis ke tabel resmi Samsung `ASV0 v15` (aman untuk semua chip `ASV0..ASV15`), sambil tetap menjaga kurva termal dingin `58/62/66/72/80/90°C` (`0019`).
6. **2-Stage Screen-Off Throttling & 20-Menit Delayed Deep Sleep (`init.power.rc` + `init.te`):**
   - Saat layar mati (`vendor.touch.inhibit=1`): menahan wakelock kernel berjangka **`zeroflte_pre_deep` selama 20 menit (`1200000000000 ns`)** agar perangkat tidak terburu-buru masuk `deep` sleep untuk penggunaan jeda singkat, sambil langsung membatasi `policy0` & `policy1` ke **`800 MHz`** dan GPU `14ac0000.gpu` ke **`266 MHz`** (hemat daya & dingin selama layar mati). Setelah 20 menit layar mati terus-menerus, timer `zeroflte_pre_deep` habis otomatis dan kernel masuk `deep` (`STOP`) sleep penuh. Saat layar menyala (`vendor.touch.inhibit=0`), wakelock langsung dilepas dan frekuensi penuh (`1.5 GHz` A53 / `1.6 GHz` A57 / `700 MHz` GPU) dipulihkan instan.
7. **Perbaikan Manifest, Skrip Build, `ueventd.rc`, & SELinux:**
   - `manifests/zeroflte_rising17.xml`: Menambahkan `<project path="kernel_src/SM_G92X" name="eiarf/SM_G92X" remote="gh_s6" revision="lineage-22.2-android15-6.6" clone-depth="1" />` agar manifest 100% mandiri.
   - `scripts/build_kernel_linux.sh`: Auto-detect `KERNEL_SRC` (`$ROM_DIR/kernel_src/SM_G92X` atau sibling `SM_G92X`) dan auto-reset source tree (`git checkout -f HEAD && git clean -fd -e out`, menjaga cache objek `out/`) bila ada patch kernel yang bertambah/berubah.
   - `ueventd.samsungexynos7420.rc`: Menghapus baris invalid 4-kolom di baris 148 (`/sys/bus/iio/devices/iio:device* 0664 system radio`).
   - `sepolicy/vendor/{init.te,gpsd.te,init_postboot_sh.te}`: Menambahkan izin `sysfs_devfreq` untuk `init`, `wakelock_use(gpsd)` + `binder_call(gpsd, system_server)` untuk `gpsd`, dan `settings_service`/`activity_service`/`content_service` untuk `init_postboot_sh` (terverifikasi lolos `precompiled_sepolicy` Android 17).
